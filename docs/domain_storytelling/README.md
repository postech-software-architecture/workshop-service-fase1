# Domain Storytelling

Diagramas que narram os fluxos de negócio da oficina como histórias entre atores, trabalho e
objetos — apoio à modelagem do domínio (DDD) e à Linguagem Ubíqua.

Os artefatos (`.png`) estão organizados por tema e numerados:

| Grupo | Fluxos |
|---|---|
| **1. Criação de OS** | criação com orçamento aprovado · com orçamento reprovado |
| **2. Gestão da OS** | execução do serviço · orçamento expirado |
| **3. Gestão de estoque** | estoque crítico · estoque com itens disponíveis |
| **4. Gestão de clientes** | novo cliente · atualização · inativação (e bloqueio por OS aberta) |
| **5. Gestão de veículos** | novo veículo · identificação · divergência cadastral · inativação (e bloqueio) |

Abra os arquivos `.png` deste diretório para visualizar cada história.
